# Activity 6 – GreenFN: Fitness and Nutrition Website

## Overview
This activity involved using an AI website-building tool to develop **GreenFN**, a fitness and nutrition platform designed to help users build healthier and more sustainable habits.

## Objective of the Website
The primary objective of GreenFN is to provide an accessible and user-friendly fitness and nutrition platform that promotes a healthier lifestyle through personalized workout plans, meal recommendations, and progress tracking. It aims to help individuals work toward their fitness goals through exercise routines based on their physical information, activity levels, and preferences, together with nutritional guidance tailored to daily calorie and macronutrient needs. It also provides fitness resources and educational content to encourage sustainable exercise and healthy eating habits.

## Project Description and Branding
- **Website name:** GreenFN
- **Tagline:** Build a stronger, healthier you.
- **Design style:** Modern, premium, athletic, and minimalist.
- **Primary color:** Dark forest green.
- **Secondary color:** Off-white.
- **Accent color:** Lime green.
- **Design elements:** Clean typography, rounded cards, subtle animations, and fitness photography.
- **Responsive design:** Intended for desktop, tablet, and mobile, with responsive navigation and a mobile menu.
